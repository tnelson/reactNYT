Privacy policy

This demo logs every 3-number sequence guess made, along with a timestamp and a random per-session ID. These are stored in a Firebase cloud database, so that the app's code can be a better resource for students using Firebase.

Logging in is not necessary to use the demo. We added login support so that the demo would be a better resource for students taking our class. If a user logs in with Google, their name and email are logged alongside the above. No other Google-account data is retained.

The demo does not share retrieved data with third parties or use it for advertising.

Use of Google API data follows the Google API Services User Data Policy. Contact Tim Nelson with questions about this policy.
